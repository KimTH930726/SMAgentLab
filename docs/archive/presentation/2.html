03-2SEMANTIC LAYER

시맨틱 캐시

문자열 일치 아닌 의미 유사도로 캐시 히트 판정

  • 키 namespace + agent_type 로 격리(캐시 안 섞임)
  • 임계값 기본 0.88(한국어 최적화) · 운영값 0.92
  • TTL 1800초(30분)
  • 장애 대응 Redis 다운 → 캐시만 꺼지고 서비스는 정상

03-4CONTEXT MAINTENANCE

대화 메모리

ConversationSummaryBuffer + Semantic Recall

  • 요약 트리거 4회 교환마다 오래된 대화 LLM 요약
  • Working Memory 최근 2회 교환은 항상 raw로 유지
  • Semantic Recall 유사도 ≥ 0.45 과거 요약만 리콜, 최대 2개
  • 백그라운드 요약 생성이 응답 지연을 만들지 않음
예시
"아까 쿠폰 관련 쿼리 다시 알려줘"
↓ 유사도 0.72
1~2번째 교환 요약 리콜 성공
