## 3. 근거 없음 즉시 판정 켜기

같은 출력의 "근거 없음 즉시 판정" 표에서 lexical 기준 후보를 다시 확인한다(10/6: `(0.50, 0.05)` → 골든 거짓 거절 0/88, 답 없음 35/60 차단).

```bash
# .env
POLICY_ABSTAIN_MIN_SCORE=0.50
POLICY_ABSTAIN_MIN_PARAM_RANK=0.05
# restart가 아니라 up -d — compose 환경변수 변경은 컨테이너를 다시 만들어야 반영된다
docker compose -f docker-compose.yml -f docker-compose.dev.yml up -d --no-deps backend
docker exec ops-backend printenv | grep POLICY_ABSTAIN    # 들어갔는지 확인
```

주의(2026-10-07 배포 때 발견): compose는 `docker-compose.yml`의 backend `environment:`에 **나열한 변수만** 컨테이너에 넣는다 —
`.env`에만 적으면 반영되지 않는다. v2.128 변수(GLOSSARY_MATCH_MODE·GLOSSARY_MINING_INTERVAL_HOURS·POLICY_ABSTAIN_*·INHOUSE_LLM_TIMEOUT)는
배포 때 그 목록에 추가했다(빈 값 = 꺼짐/기본값).

확인(실제 `/api/chat/stream`): 무관 질문 5개 이상 × 3회 → 전부 "관련 지식을 찾지 못했습니다". 점수로 못 거른 나머지(약 40%)는 LLM 거절에
맡겨지므로 결과에 지어낸 답이 섞이면 질문·횟수를 기록한다(→ 답변 사후 점검 검토 근거). 정책 질문 A1·A2와 외부서비스DB 매뉴얼 질문 답 동일.
