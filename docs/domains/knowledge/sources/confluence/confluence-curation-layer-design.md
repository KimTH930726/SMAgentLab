## 2. 위치 — 수집기의 한 레이어 (에이전트·별도 PoC 아님)
```
[수집] 컨플 → 원문 원장(rag_source_document, storage HTML 통째 = 기준)      ← ① 수집기 보강(결정적, LLM 0)
   │      + 페이지 메타(URL·space·수정 시각·작성자·라벨) + 이미지·첨부 목록
   ▼
[파생 A] 조각(rag_knowledge, 지금 그대로) — 이미지 자리에 "[이미지: 파일명 — 원문 참조]" 표시
   │
   ├─ ② 팀 진단(배치, 숫자·후보만) — 인벤토리·노후 후보·중복 후보·업무 묶음 제안·질문 공백
   │
   ▼
[파생 B] 정제 지식(업무 단위 초안, 문장마다 출처 조각 id) — ③ AI 초안 → ④ 사람 검수 → active
   │
[검색] A·B 같은 표(rag_knowledge)·같은 검색 — B가 이기는지는 평가 게이트 지식 축으로 잰다(⑤)
```
- **원문 = 기준, 조각·정제 지식 = 파생물**(10/07 원문 원장 결정 그대로). 컨플 원본은 건드리지 않는다(설계안 원칙 1과 같음).
- 정책서 v0가 이미 같은 모양이다: 원문 통째(`policy_item.raw_body`) + 파생값(파라미터) + 사람 승인 + 원문에 없는 값 빨강. 정제 지식은 **지식 쪽의 같은 패턴**.
- 단계는 하나의 작업 흐름(스크립트·배치 + 검수 화면)으로 — 설계안 원칙 6 "멀티 에이전트 대신 단일 오케스트레이터"와 같다.

## 3. 업계 조사 요지 (출처는 §9)
- **이미지**: 큰 제품도 페이지 안 이미지를 거의 못 읽는다(Rovo는 페이지 이미지 미지원 — 기능 요청 열림, MS Graph 컨플 커넥터는 첨부 미색인).
  Rovo 권장 대안 = "핵심은 글로 적어 두라". draw.io는 첨부 원본 XML(`X.drawio`)에서 도형·연결 글자를 **환각 없이** 뽑을 수 있다.
  VLM 다이어그램 해석은 결정 노드 오독·없는 연결 지어내기가 흔하다(논문 다수) → **감지·안내는 전부, 추출은 결정적인 것부터, VLM은 꼬리표 달고 마지막.**
- **AI 초안 + 사람 검수**: 주류는 원문은 두고 별도 초안 층(JSM Rovo KB 초안 "미게시", ServiceNow Now Assist "AI 작성, 저장 전 검토", 기존 KB 있으면 안 만듦).
  신선도는 검증자 + 주기(Guru·Glean). 함정 = 검수가 지루하면 그냥 승인(자동화 편향), 주인 없는 내용은 안 고쳐짐.
- **정제가 정확도를 올리나 — 조건부**: 맥락 머리(Anthropic contextual retrieval) 실패 49%↓ 같은 긍정도 있지만, 생성 확장은 **강한 검색기엔 대체로 해**(Weller 2024),
  거르지 않은 생성 질문은 손해(Doc2Query--). 우리도 맥락 머리 임베딩이 지식에선 손해였다(Recall@3 95.3→94.3%, trustkit §7).
  → **정제 지식은 "더 넣기"가 아니라 실패 질문을 고치는 표적 처방**이어야 하고, 전/후 게이트 필수.
- **노후화**: 수정일·조회수로 "검토 후보" 표시만, 적재에서 빼지 않음(Confluence 자동화 "비활성 페이지", 보관 앱). 수정일 ≠ 내용 최신(이동·라벨도 시계를 바꿈).

## 4. 설계안 검토 — 받아들인 것 / 바꾼 것 / 뺀 것
| 설계안 | 판단 | 우리 식 |
|---|---|---|
| 원본 불변, 별도 레이어 | **채택** | 원문 원장 + 파생 B. 저장은 지금 Postgres+pgvector — **Qdrant·Object Storage는 안 씀**(새 인프라 = 폐쇄망 반입 부담, 규모상 불필요) |
| 질문이 먼저(실패 질문부터) | **채택 — 이미 가는 길** | 운영 질의 감시(v2.187~)의 진단·표본 채점이 "실패 질문" 공급원. 팀 질문 50개는 **잠근 골든셋(사람 문항)** 으로 — 기존 locked 개념 재사용 |
| 고위험 업무 예외·2인 검수 | **보류** | 지금 검수 흐름은 담당 1인. 고위험 목록이 팀에서 오면 그 영역만 2인 — 실제로 받은 뒤 |
| 출처 없는 사실 문장 금지, AI 제안은 메모로 | **채택(핵심)** | 문장마다 출처 조각 id. 원문 조각에 없는 숫자·명령어·절차는 **빨강**(정책서 검토 화면 규칙 재사용). 메모는 색인 제외 |
| AI는 판단하지 않음(후보·표시만) | **채택** | 중복·충돌·노후 = 후보/표시, 확정 = 사람. AI 판단 원장(`ops_ai_decision`)에 새 kind로 남겨 번복률을 잰다 |
| 결정적 작업은 코드로 | **채택** | 수집·해시·날짜·버전·이미지 개수·draw.io XML = 코드. LLM은 업무 묶음 제안·초안·충돌 설명만 |
| 2축 분류(업무 영역 × 지식 유형) | **1축만** | 업무 영역 = 지금 영역 트리(넣을 곳 판단 그대로). 지식 유형(트러블슈팅·절차 등)은 **정확도 효과를 재기 전엔 안 만듦**(YAGNI) — 실패 질문이 유형으로 갈리면 그때 |
| 2트랙 검색(승인 지식 우선, 원문 폴백) | **바꿈** | 따로 검색하지 않고 **같은 표·같은 검색**. 정제 지식이 이겨야 한다면 점수로 이겨야 함 — 우선 가중은 게이트로 재서 넣는다(가중 없이 시작). "미검수" 표시 대신 근거 카드에 출처(원문 조각/정제 지식)와 원본 링크 |
| STALE(원본 버전 바뀌면) | **채택, 현행화와 한 몸** | 정제 지식은 출처 조각의 `confluence_version`을 들고 있음 → 원문이 바뀌면 정제 지식도 "확인 필요". 감지는 `confluence-sync-research` MVP(감지 자동·반영 사람)와 같이 — MCP 게이트웨이 도구 목록 대기 |
| ACL 다른 원본은 묶지 않음 | **질문으로** | 지금 컨플 권한을 저장하지 않고, 적재한 지식은 로그인 사용자 누구나 읽음. **이미 컨플 제한 페이지가 들어왔을 수 있다** → 결정 필요(§7) |
| 이미지: 감지 전체·추출 선별 | **채택, 순서만 바꿈** | ① 감지·자리 표시·원본 링크(전부) → ② draw.io XML(결정적) → ③ 스크린샷 OCR(실패 질문에 걸린 것만) → ④ VLM은 "AI 설명" 꼬리표 + 검증 전 답 근거 금지 |
| Claude가 1팀 진단 리포트 수동 생성 | **바꿈(보안)** | 컨플 원문은 이 세션(Claude)이 읽지 않는다(사용자 지침 9/16). 진단은 **스크립트 + 로컬 LLM**, Claude는 숫자·구조 요약만 받아 설계 |
| 4문항 검수 | **채택** | 틀린 사실 / 빠진 내용 / 지울 것 / 오너 — 정정 요청 검토 화면 모양으로 |
| A vs A+B, 정답률·Recall@5, 검수 시간 | **채택** | 평가 게이트 지식 축(#96) 그대로. 고위험 오답 0은 고위험 목록이 오면. 검수 시간은 검수 화면이 기록 |

## 5. 하는 것(MVP) — 단계와 산출물
**① 수집기 보강 (결정적, LLM 0) — 가장 먼저, 정제 없이도 바로 이득**
- 페이지 메타를 원장에 저장: URL·space key·수정 시각(version.when)·작성자·라벨(+ 일괄 등록도 원장에 남는지 확인 — dev DB엔 컨플 원장 0건).
- 이미지·첨부·다이어그램 **목록과 개수**를 원장에(파일명·alt·위치한 제목 경로·종류: 첨부 이미지/외부 URL/draw.io/gliffy).
- 조각 본문의 이미지 자리에 `[이미지: 파일명 — 원문 페이지에서 확인]` 한 줄 — 답이 "문서에 그림으로 있음 → 링크"로 안내할 수 있게.
  (주의: 글자가 늘어 검색이 바뀐다 → 게이트로 확인. 손해면 본문 대신 메타로만 두고 근거 카드에만 표시)
- 근거 카드에 **원본 페이지 링크**(정책 근거 카드처럼).
- 적재 검사(`check_ingest`)에 "이미지만 있는 섹션 수 · 이미지 많은 페이지" 한 줄 — 작성 가이드 규칙 7 후보("핵심은 그림 말고 글로도").
- 다이어그램 매크로 잔재를 줄째 지우는 규칙(`"false auto top"`)이 같은 줄 정상 글자도 지우는지 — 리팩터링 가드 재검토(개발 규율).

**② 팀 진단 리포트 (배치, 숫자·후보만)** — 사용자: "최상단 URL을 주면 팀별로 싹 훑어 어떤 업무로 나누고 어떤 구조가 최적인지"
- 입력: 팀 최상단 페이지(트리 수집 기존 기능, 최대 500페이지).
- 인벤토리(코드): 페이지 수 · 수정 시각 분포(1년/2년+ 노후 후보) · 이미지·draw.io 비율 · 헤딩 없는 페이지 · 표만 있는 페이지 · 매크로 안 핵심 내용 · 같은 내용(해시) 중복.
- 업무 묶음 제안(로컬 LLM + 기존 넣을 곳 판단): 페이지·섹션을 지금 영역 트리에 넣어 보면 어디로 가나, 어디에도 안 맞는 묶음(새 하위 영역 후보).
- 비슷한 내용 후보(기존 0.88 유사도) · 서로 다른 값(충돌 후보: 같은 주제·다른 숫자 — 4번 실측처럼 숫자만 다른 쌍).
- 질문 공백: 팀 질문(받으면)·운영 질의 중 근거 없음/약함.
- 산출물: 팀별 진단 화면 1장(카드 = 큰 숫자 + [자세히]) + **작성 가이드에 맞춘 팀별 손볼 목록**("이 12페이지는 헤딩 없음", "이 5페이지는 그림만").

**③ AI 초안 (실패 질문 표적)** — "중복된 내용은 다듬고, 우리 구조에 맞게 1차로 깎아 주고"
- 대상 = 실패 질문(운영 질의 감시 + 팀 질문)이 걸린 업무 묶음만, 처음 20~30건.
- 로컬 LLM이 출처 조각들 → 업무 단위 정제 지식 초안: 문장마다 출처 조각 id, 원문에 없는 숫자·명령어 = 빨강, 충돌은 합치지 않고 양쪽 + "담당 확인".
- 이미지가 걸려 있으면 ②의 draw.io XML 글자까지만(결정적). OCR·VLM은 ④ 이후.

**④ 사람 검수 (4문항)** — 정정 요청 검토 화면을 재사용(새 화면 최소): 틀린 사실 / 빠진 것 / 지울 것 / 오너 → [등록]. 검수 시간 기록.
- 등록되면 `rag_knowledge` 한 줄(source_type 새 값, 출처 조각 id·버전 목록). 출처 조각은 그대로 둔다(지우지 않음 — 정제가 손해면 정제만 내림).

**⑤ 측정** — 평가 게이트 지식 축: 팀 질문(잠근) + 합성 문항으로 A(지금) vs A+B 전/후. 나빠짐 0이 아니면 정제 지식 채택 안 함(정확도 하락 금지).

## 6. 안 하는 것 + 다시 볼 조건
| 안 하는 것 | 다시 볼 조건 |
|---|---|
| Qdrant·Object Storage 등 새 저장소 | 지식 수만 건·이미지 원본 보관이 필요해질 때 |
| 지식 유형 2번째 축 | 실패 질문이 유형(절차·트러블슈팅 등)으로 갈린다는 게 측정으로 보일 때 |
| 정제 지식 우선 가중 | 정제 지식이 맞는데 순위에서 밀리는 게 게이트에 보일 때 |
| VLM 이미지 전수 해석 | ③~⑤에서 "그림에만 있는 답" 실패가 주 몇 건 이상 쌓일 때(선별부터) |
| 고위험 2인 검수 | 팀이 고위험 목록을 줄 때 |
| 컨플 원본 자동 수정(역기입) | 하지 않음 — 원본은 팀 것. 손볼 목록·가이드로만 |
| 자동 재적재·자동 STALE 해소 | MCP 게이트웨이 도구가 오고 감지가 안정된 뒤(현행화 설계와 같이) |
| 팀 전체 정제 | 1팀 파일럿에서 정확도 + 검수 시간이 둘 다 맞을 때 |

## 7. 결정 필요
1. **파일럿 1팀** — 문서 많고 이미지 많은 팀. 팀에서 받을 것: 최상단 URL, 실제 질문(30 개선 / 20 평가 — 못 받으면 운영 질의로 대신), 오너.
2. **컨플 권한(ACL)** — 지금은 사용자 개인 PAT로 가져온 걸 로그인 사용자 누구나 본다. 제한 페이지가 섞여 들어왔을 수 있다 → ① 적재 때 제한 페이지 건너뛰기(권장, 수집기 보강에 포함) ② 권한 저장 후 검색 시 거르기(무거움) ③ 지금대로(팀 공개 공간만 적재한다는 운영 규칙).
3. **컨플 원문의 LLM 경로** — 용어 자동 추출은 시스템 LLM(운영 = 게이트웨이)으로 컨플 조각 묶음을 보낸다. 채팅 답도 게이트웨이로 컨플 조각을 보낸다(시스템 안 처리). 진단·초안(②③)은 로컬 LLM으로 둘 생각 — 이 경계가 맞는지.
4. **이미지 자리 표시를 본문에 넣을지** — 넣으면 답이 "그림 참조 + 링크"를 말할 수 있지만 검색 점수가 바뀐다 → 게이트로 재고 결정(권장), 손해면 근거 카드에만.

## 8. 순서 제안
① 수집기 보강(1~2일 규모, 정제 없이도 이득: 이미지 안내·원본 링크·노후 표시) → 운영 질의 감시 남은 단계(실패 질문 공급) → ② 진단 1팀 → ③④ 초안·검수 20~30건 → ⑤ 게이트.
①은 MCP 게이트웨이 전환과 겹치는 부분(수집 경로)이 있어 **저장 모양(원장 칸)은 지금, 가져오는 길은 게이트웨이 도구 목록을 본 뒤** 맞춘다.
