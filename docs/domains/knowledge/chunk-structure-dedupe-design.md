## 3. 업계 방식 (출처)

- **거의 같은 글 찾기는 글자 기준으로 한다**: shingle(글자 n-gram) Jaccard / MinHash(Broder 1997 "On the resemblance and containment of documents"),
  SimHash(Charikar 2002; Google 웹 크롤 중복 제거, Manku 2007). 의미 임베딩은 "같은 뜻"을 잡지 "같은 글"을 잡지 않는다.
- **반복 양식(boilerplate) 걸러내기**: 여러 문서에 반복되는 블록을 본문에서 구분(Kohlschütter 2010 "Boilerplate Detection using Shallow Text Features",
  jusText). RAG 도구도 같다 — Unstructured `chunk_by_title`의 `combine_text_under_n_chars`(짧은 조각을 이웃과 합침),
  LangChain `MarkdownHeaderTextSplitter`(제목은 조각 본문이 아니라 메타데이터로).
- **완전 일치는 해시로 적재 때 거른다**: 데이터 파이프라인의 정확 중복 제거(exact dedup — 정규화 후 해시 비교)가 표준 1단계.

## 4. 하는 것 (MVP)

### ① 청크 구조화

**A. 제목만 있는 조각은 이웃과 합친다** — 측정: 홈페이지 1,883 → 1,782조각(−101), 승인 대기 44건이 원인째 사라짐.
- "제목 같은 줄" = `#` 제목 + **번호 제목 줄**(`1.2.`, `05-2.1.3.`, `(참고) ○○`처럼 60자 미만 · 문장 끝 없음).
- 조각의 본문(제목 같은 줄 제외)이 30자 미만이면 같은 페이지 **다음 조각 앞에** 붙인다(마지막이면 앞 조각 뒤). 제목은 다음 조각의 상위 경로(heading_path)에도 남긴다.

**B. 묶음 양식 줄은 "비교·검색"에서만 뺀다(원문은 그대로)**
- 같은 공간 안 **5쪽 이상에 똑같이 나오는 줄** = 양식 줄(측정: 줄의 16.1%). 원문·조각 본문에서 지우지 않는다(필드 이름처럼 뜻이 있을 수 있음).
- 쓰는 곳은 두 군데: (1) 아래 ③ 중복 판정의 글자 비교에서 뺀다, (2) [실험] 임베딩할 글에서 뺀다 — (2)는 검색 게이트를 통과할 때만.

### ② 완전 일치는 등록 때 거부

- 기준은 **임베딩 점수가 아니라 글자**: 공백·줄바꿈을 정리한 본문이 **같은 컬렉션의 사용 중 지식**(또는 같은 묶음의 앞 조각)과 완전히 같으면 저장하지 않는다.
  화면의 "100%"는 의미 유사도를 반올림한 값이라 같은 글이 아닐 수 있다(측정: 0.98 이상 89건 중 같은 글 66건).
- **보이게 한다**(대체 처리는 보이게): 적재 결과·등록 응답에 "같은 글이 있어 건너뜀 N건(#기존 id)"을 표시한다. 조용히 버리지 않는다.
- 측정 효과: 승인 대기 457 → 391(−66). 사용 중 지식끼리의 완전 일치 105건은 기존 "지식 중복 조각 정리"(knowledge_dedupe) 검사 대상으로 넘긴다.
- 제외할 경우: 같은 원본을 다시 등록하는 교체 경로(옛 조각은 먼저 내려감) · 다른 컬렉션의 같은 글(다른 맥락일 수 있음).

### ③ 중복 판정 2단 (① + ②를 묶는 규칙)

1. 의미 유사도 0.88 이상인 짝을 찾는다(지금과 같음).
2. **양식 줄을 뺀 글자 차이**(difflib 비율 또는 글자 3-gram Jaccard)가 **0.8 이상일 때만** 승인 대기. 0.8 미만 = 같은 양식의 다른 페이지 → 정상 등록하고
   AI 감사 로그(중복 의심)에 "의미만 비슷해 등록" 한 줄을 남긴다.
- 측정 효과: 승인 대기 457 → 약 165(같은 글 66은 ② 거부, 0.8 미만 226은 정상 등록). **226건이 검색에 들어가므로 정확도 게이트 필수.**

  청커의 기존 가드(짧은 도입부 재부착 `_emit_carry`, 최소 길이 필터 `_has_body`, 표 이중 저장 방지 `_table_already_in_text`, always_split 분리 모드)를
  하나씩 "왜 있었나"부터 다시 보고 새 규칙과 겹치지 않게.
