# 시나리오 리허설

현안공유회 시연(11/11) 흐름을 영상 없이 사본에서 다시 돌려, 장면마다 통과/실패를 냅니다.
단위 테스트와 E2E는 기능을 하나씩 봅니다. 리허설은 질문 → 근거 → 정정 신고 → 승인 → 다시 질문이 **한 줄로 이어지는지**를 봅니다.

**언제 돌리나:** 폐쇄망 반입 전 · PoC 전 · 큰 머지 전.

## 돌리는 법

```bash
scripts/rehearsal/up.sh                 # 사본 띄우기
node scripts/rehearsal/run.mjs          # 장면 실행 (10~20분, 로컬 LLM)
scripts/rehearsal/down.sh               # 사본 정리
```

- `up.sh`는 `.env`의 `IMAGE_TAG` 이미지를 씁니다. 그 값이 없으면 `latest`를 씁니다.
  지금 소스로 확인하려면 `REHEARSAL_SOURCE=1 scripts/rehearsal/up.sh`로 돌립니다. 이때 백엔드만 소스를 마운트하고, 화면은 이미지 그대로입니다.
- 사본은 아래와 같습니다. 원본 `opsdb`는 `pg_dump`로 읽기만 하고, 정정·승인·사용자 추가는 사본에만 씁니다.

| 항목 | 사본 |
|---|---|
| DB | `opsdb_rehearsal` |
| 백엔드 | `ops-backend-rehearsal` (:8001) |
| 화면 | `ops-frontend-rehearsal` (:8502) |
| Redis | 5번 칸 |
| 네트워크 | `smagentlab_rehearsal` |

- 원본 스택(`ops-postgres`·`ops-redis`·`ops-backend`)이 떠 있어야 합니다. 사본 백엔드 설정을 원본 백엔드에서 읽기 때문입니다.
- 사본이 원본과 다르게 받는 설정은 DB, Redis 칸, 컨플 동기화(끔), JWT 키(무작위 — 사본에서 받은 토큰은 원본에서 안 통함)입니다.
  원본에 모르는 외부 연결 칸(`*_URL` 등)이 생기면 `up.sh`가 멈춥니다. 사본 값을 정해 준 뒤 다시 돌립니다.
- `run.mjs`는 시작하기 전에 docker로 두 가지를 확인합니다. 부르는 포트가 사본 컨테이너의 포트인지, 그 컨테이너가 사본 DB에 붙어 있는지입니다. 하나라도 아니면 아무것도 쓰지 않고 멈춥니다.
- Redis는 같은 인스턴스의 다른 칸(5번)을 씁니다. 메모리 한도(256MB, LRU)를 원본과 나눠 쓰므로, 리허설 중에는 원본 답 캐시가 조금 일찍 밀려날 수 있습니다.
- 결과는 콘솔 표와 `scripts/rehearsal/out/result.json`에 남습니다. 실패한 장면은 스크린샷도 같은 폴더에 남습니다.
  `out/`은 git에 올리지 않습니다. 답 원문은 어디에도 찍지 않고 개수·있음/없음만 남깁니다.

## 장면과 통과 기준

| 장면 | 내용 | 통과 기준 |
|---|---|---|
| 1 | 정책 질문 | 근거 없음 답이 아님 · 정책 근거 카드 있음 · 없는 번호 칩 0 |
| 2 | 되묻기 | 선택지가 뜸 · 지정 선택지를 누르면 답이 나옴 |
| 3 | 정책+시스템 섞인 질문 | 정책 근거와 문서 근거가 둘 다 있음. 답이 흔들리면 캐시를 비우고 최대 2번 다시 묻고, 다시 물은 횟수를 표시 |
| 4 | 운영 지식 질문 | 문서 칩 ≥1 · `target_id` 근거 카드 있음 |
| 5 | 답변 틀림 → 정정 신고 | "정정 신고 접수됨" (4가 통과해야 실행) |
| 6 | 담당자 승인 | 정정 카드가 뜨고 승인 응답 2xx. AI가 고른 대상이 다르면 `target_id`로 바꾸고 표시 |
| 7 | 다시 질문 | 처리 알림이 뜸 · 답에 `expect_after` 값이 들어 있음 |
| R | 지식 등록 | 비슷한 지식 창이 뜸 · [등록 안 함]을 누른 뒤 지식 수 그대로 |

## 데이터가 바뀌면

질문·컬렉션·대상 지식 id·정정 문구는 모두 `scenario.json`에 있고, 코드에는 데이터 값을 두지 않습니다.
1차 적재 뒤에는 `target_id`·`base_knowledge_id`·질문을 새 데이터에 맞게 바꿉니다.
